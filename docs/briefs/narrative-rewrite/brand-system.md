# 新禾智飞品牌系统连续稿

展会、印刷品和线下活动由不同供应商分批制作。旧海报、灯箱、展位画面和产品截图墙各自可以使用，放在一起却很难看出它们来自同一个品牌。每开一批物料，制作人员都要重新决定标识、字体和版式。

我把这些反复出现的选择整理成场景矩阵、规范和模板。制作一张工作证时，先查展会或线下活动对应的语境，再根据版面方向、中英文信息和可用空间选择标识组合。随后套用姓名、职务和品牌识别的固定层级，交付前核对最小尺寸、留白、色值和印刷条件。

旧物料说明品牌已经有真实触点，也暴露了三个需要统一的问题。制作人员要知道该用哪种标识，密集信息需要稳定层级，不同尺寸与媒介需要可以直接开始的模板。新系统从这三类选择入手，没有否定旧物料已经完成的传播任务。

标识系统保留四种组合，用来覆盖中英文、横版与竖版，以及品牌和产品语境。场景矩阵说明每种组合在哪里使用，最小尺寸和留白规则保证标识进入成批制作后仍能保持稳定。

颜色和字体继续回答怎样保持一致。识别色、辅助色与特殊色各有用途和禁用组合，中文与英文字体按标题、正文和辅助信息分级。色值、字号与间距可以直接进入设计文件，实体生产前仍要根据材质核对。

同一套规则随后进入投放框架、社媒模板和实体物料。写字楼、电梯和户外画面先处理比例与安全区，社媒模板固定内容位置和裁切范围，工作证、礼品袋与停机垫分别检查小尺寸信息、大面积底色和行业场景。

生成工具用于概念与场景素材发散，也用于静态素材的动态化尝试。我负责标识结构、组合数量、场景矩阵、色彩层级和模板取舍。当前交付包括 24 页规范与标识、色彩、字体、媒介、社媒和物料 6 个子系统。新规范、模板和物料都处在提案阶段，还需要打样和真实制作验证。
