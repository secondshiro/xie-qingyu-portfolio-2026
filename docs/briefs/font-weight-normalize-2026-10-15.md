# 案例页字重归一（2026-10-15）

## 起因

用户浏览修订后的房产 GIS 案例页时指出，05 设计取舍第 01 张卡片标题「业务状态和当前选中分别表达」字重过粗，与规范不符，并要求把全文同类用法一并改回。

## 排查方法

用 Playwright 读取四个案例页与首页所有 `h1` 至 `h4` 的计算字重，再全量扫描字重不低于 600 且自带文字的元素。两份脚本与原始数据留在 `artifacts/gis-font-weight-20261015/`（`measure.mjs`、`measure-home.mjs`、`scan-bold.mjs`、`weights.json`、`bold-scan.json`）。

## 改前分布

以房产 GIS 页 24 个标题为例。

| 位置 | 字号 / 字重 | 判定 |
| --- | --- | --- |
| 首屏 `h1` | 44px / 400 | 合规 |
| 章节 `h2` × 8 | 26px / 400 | 合规 |
| 工作面 `h3` × 3 | 18px / 500 | 合规 |
| 参照卡 `h3` × 3（04） | 24.8px / 560 | 不合规 |
| 取舍卡 `h3` × 3（05） | 24.8px / 560 | 不合规 |
| 价值卡 `h3` × 3（06） | 24.8px / 560 | 不合规 |
| 边界卡 `h3` × 2（06） | 24.8px / 560 | 不合规 |
| 页尾 `h2` | 24px / 560 | 不合规 |

另有字重 700 的两类，来自 `<b>` 的浏览器默认值。对应规则只设了字号，没有设字重，因此直接落在默认值上。

- `.evidence-key b`：房产 GIS 3 处
- `.workspace-notes b`：房产 GIS 3 处、品牌系统 10 处

根因在 `global.css` 的 `h1, h2, h3 { font-weight: 560 }`。该声明只被三处覆盖，首屏 `h1` 与章节 `h2` 覆盖为 400，工作面 `h3` 覆盖为 500，其余向下继承或保持浏览器默认。

## 判定依据

`DESIGN.md` 的 Typography 层级只定义两档标题字重，Headline 章节标题 400，Title 工作面标题 500，没有 560。全站 `h2` 实测均为 400，包括首页四张作品标题与案例章节标题，案例页尾 `h2` 是唯一例外，属漏网而非有意例外。

## 改动

只改 `src/styles/case-study.css`，15 增 1 删。

| 选择器 | 改动 |
| --- | --- |
| `.reference-card h3`、`.value-card h3`、`.decision-card h3`、`.workspace__header h3`、`.boundary-card h3` | 组合规则内补 `font-weight: 500` |
| `.case-copy h3` | 新增规则，`font-weight: 500` |
| `.evidence-key b`、`.workspace-notes b` | 新增规则，`font-weight: 500` |
| `.case-closing h2` | 新增规则，`font-weight: 400` |

未改动的加粗项均属有意设计。导航与首页的品牌名「谢擎宇」为 650 或 600，证据类型标签「留存材料」「本次提案」为 650，Edgecase 与执行网交互示意里的 `strong` 为 700，后者模拟的是界面控件文字。

备份在 `backups/font-weight-normalize-20261015/`，改前 `case-study.css` 的 SHA-256 为 `6cda48ce…`，改后为 `3369e208…`。
