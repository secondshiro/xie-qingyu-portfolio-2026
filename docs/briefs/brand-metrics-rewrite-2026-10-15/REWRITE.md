## 原稿的主要问题

先按陌生读者视角读一遍改写前的页面。首屏能给的是「低空科技企业 + 物料混乱 + 我设计了一套规范」，读完八节可以复述作者的职责，但很难复述他具体改了哪几处、依据什么改。

| 位置 | 问题 | 对应指标 |
| --- | --- | --- |
| 首屏 summary | 停在「设计了一套标识、颜色、字体和模板规范」，读者看不到具体改动落在哪几个产物上 | 对能力判断有用 |
| 02 正文 | 「新规范需要安排它们的主次」是概括表述，没有说明旧画面哪里出了问题、新规范改成了什么 | 问题接到设计决定、语言简洁且信息不丢 |
| 03 导语与 00 卡片 | 同一件东西出现四种叫法，即场景矩阵、场景选用表、标识选用表、选用表 | 语言简洁且信息不丢 |
| 03 导语 | 只说「按用途查标识」，没有说明表按什么分行、分几类，读者无法复述选用依据 | 方法来源与用法清楚 |
| 04 卡片 | 三张卡片都把规则说成「按用途」「按适用条件」「按层级」，读完不知道色值、占比与字重的具体约定 | 方法来源与用法清楚、结论能推动工作 |
| 04 → 05 用词 | 04 与 03 的图注说「标识」，05 标题与辅助图形组件的步骤标签说「标志」 | 语言简洁且信息不丢 |
| 06 三节说明 | 「图片和信息也要重新安排」「查看比例和信息量变化后怎样安排」没有落到尺寸、位置或具体版本 | 问题接到设计决定 |
| 07 卡片 | 「我负责的判断」四条都是类别名，没有说明判断依据；另有一条把「标识结构」算作本人产出，材料只支持它是已有标识 | 贡献与职责准确 |
| 00 导语末句、08 卡片 | 「这些选择可以在同一套规范里找到依据」「作为交给供应商的依据」属于对文章价值的自我说明，没有给读者新信息 | 语言简洁且信息不丢 |
| 多处图注 | 五条图注基本在复述替代文本，只描述画面里有什么，没有指出该核对什么 | 相邻段落连续、语言简洁且信息不丢 |
| 04 与 08 | 交付物只有文字说明，页面上没有出现过规范册本身，读者无法确认这份规范是什么形态 | 对能力判断有用 |

## 结构变动

以下四项由用户确认后执行，均不在原草稿范围内。前三项属第一批，第四项属第三批。

**一、辅助图形移到标识章节之后。** 原顺序为 03 关键判断、04 视觉语言、05 辅助图形。辅助图形由标识基础形延展而来，属品牌基础系统，接在颜色与字体之后会让它和应用部分的距离更近。改为 03 关键判断、04 辅助图形、05 视觉语言，编号与目录同步调整，锚点 `#auxiliary` 与 `#language` 不变。改后基础系统三节连续，应用部分从 06 开始。

**二、补上辅助图形的设计来源。** 用户提供：辅助图形的灵感来自原标识中的斜向笔画与内折角，这些结构带有明确的方向感，也与品牌的飞行主题呼应。据此改写 04 的导语，替换原来只写「提取标志中的斜向笔画和内折角」的一句。

**三、启用四张此前未被引用的规范页。** 四张都在 `media/final/` 内，本轮加入页面。

| 素材 | 加入位置 | 作用 |
| --- | --- | --- |
| `03-context-scenes.jpg` 常用组合标识运用示意 | 03 关键判断 | 选用表说明规则，这张说明规则落到版面后的样子 |
| `10-type-usage.jpg` 品牌字体运用规范 | 05 视觉语言 | 补齐字体的第三层，即三级文字在版面中的位置与字号 |
| `01-brand-cover.jpg` 规范册封面 | 08 交付与边界 | 让规范册这一交付物在页面上可见 |
| `02-manual-toc.jpg` 基础部分章节页 | 08 交付与边界 | 说明规范分基础与应用两部分，与 03 至 06 的分节对应 |

03 与 05 的 `evidence-grid` 由两项、三项变为三项、四项；08 在价值卡片之后新增一组两项媒体。所有新增媒体沿用 `MediaStage` 与 `kind="proposal"`，尺寸按 1600×900 声明，与同节其余媒体一致。

**四、七类归类按场景与应用分层。** 用户说明选用表的七个归类参照了小鹏汽车品牌规范的场景划分。据此把 03 导语从七个名称的平铺改为两层，一层是标识出现的场合，即线上的平面物料、活动现场、网页与应用界面与海外物料；一层说明标识落到什么物件、与谁一起出现，即精品产品、无人机产品本体与品牌联合。为与 03 标题「先查使用场景」对齐，全页把这一维度的叫法由「用途」统一为「场景」，涉及首屏 `summary`、00 导语与第一步卡片、03 图注与「怎样选用」卡片；选用表的替代文本同步。分类来源按用户当日要求不写进页面，也不写入其他公开文案，只记在本文件与 `REVIEW.md`。

### 复述检查

只读首屏，可以复述这是低空科技企业的品牌物料问题，作者把四种标识组合做成按使用场景查的选用表，给颜色和字体定了层级与占比，还为投放、社媒和实体物料做了模板，旧物料已投产、新规范仍是提案。

读完 02，可以说明旧画面哪里出了问题，即四段正文用相近字号、八个数字并排且字号一致，以及新规范改成了三级分层加数字英文单独指定字体。读完 03 与 05，可以说明选用表的行按场景层与应用层分、横栏按四种组合分，并说出识别色的占比区间。

复核者的模拟阅读只用于发现编辑问题，不记为真实读者反馈。

### 最弱一节

**04 / 辅助图形**。本轮补上了灵感来源，但整节仍只有一句导语和一个组件。读者知道这组图形从哪里来，仍不知道它在规范体系里处在什么位置，也看不出它和标识、颜色字体是什么关系。补强需要说明双折面与标识共用哪部分结构，以及它在海报和封面上替代了原规范里的什么做法。现有材料只支持「提取斜向笔画与内折角」这一层，本轮不补造。

**次弱：05 视觉语言的字体分级卡**。规则写全了字体与字重，但没有说明为什么中文只取思源黑体、数字与英文为什么另用一套。这两点属于当时的选型理由，材料中没有记录。

### 删段与连读

- 删 00 导语末句「这些选择可以在同一套规范里找到依据」。它只说明文章有价值，不提供新信息。
- 删 08 卡片二末句「作为交给供应商的依据」。同样的判断在 00 卡片 04 已经出现过一次。
