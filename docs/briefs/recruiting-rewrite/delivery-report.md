# 招聘向改稿交付记录

## 修改清单

- 首页改为普通话定位，四个项目摘要分别交代实际问题、本人行动和可见产出。
- 房产 GIS 先讲工作人员的三项任务，再用 17 幢串起三个工作面；核心方案移到行业参照之前。
- Edgecase Planner 先解释 Skill，再连续呈现飞行案例的输入、追问、业务确认和未完成修正。
- 执行网先讲律师如何使用名单与 Excel，突出停止验证码识别的取舍，以及空结果和未完成分开的理由。
- 品牌系统把结果改成一段工作证制作说明，只保留一次主标识展示，并明确新方案尚未投产。
- 案例目录顺序与正文重排同步。现有路由、锚点、原型、公开素材、测试和构建配置均保留。
