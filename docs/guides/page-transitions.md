# 全站页面转场

当前范围为首页与四个公开案例，路由为 `/`、`/work/real-estate-gis/`、`/work/edgecase-planner/`、`/work/brand-system/` 和 `/work/execution-query/`。这五页之间的同源页面链接使用统一转场。

点击后，石色遮盖从底部进入，280 毫秒结束后才开始导航。目标页头部脚本在正文首次绘制前接续完整遮盖，加载完成后向顶部揭开，持续 380 毫秒。加载期间保留遮盖，不增加中间标题；加载超时会解除遮盖。

首次访问、刷新、历史前进后退和同页锚点不播放。邮箱、下载、外链、新窗口与独立业务原型沿用原有操作。减弱动效、无脚本和会话存储不可用时直接导航。

`src/components/PageTransitionHead.astro` 由首页与案例共享布局加载，负责头部初始化、跳转范围和加载接续。`src/styles/page-transition.css` 定义伪元素、石色、时长与缓动。调整时长时须同步头部脚本的等待时长；新增公开页面时也须更新脚本中的路由集合与相应检查。

`src/scripts/turntable.js` 根据首页案例链接识别返回来源，在进入任一案例前保存当前唱片与 A/B 面。点击返回首页时恢复选择；四个案例页尾都指向 `/#selected-work`，浏览器历史阅读位置继续由原生导航维护。

`tests/page-transition.spec.ts` 检查四个案例在桌面与手机上的旧页遮盖、延迟加载首帧和揭页方向，另检查键盘往返、历史位置、减弱动效与普通入口。视觉或组件修改后运行内容测试、全部浏览器测试和静态构建。

2026-09-29 用户授权将全站转场随网站更新提交并推送。远端状态以 Git 记录为准，线上部署另行核验。
