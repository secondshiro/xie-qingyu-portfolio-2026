# 案例配乐 · 随行唱片

六篇案例通过 `src/layouts/SiteLayout.astro` 加载 `CaseMusic.astro`，按案例路由匹配 `src/lib/music-tracks.js` 中的配乐。首页在唱机上显示音量与静音，案例通过右下角胶囊控制播放、静音与音量。

## 曲目与追加规则

音频位于 `public/audio/`，每个案例使用同名 M4A。低空智航曲目为《巡弋天穹》，编码为 AAC，保留完整 176 秒与 48 kHz 立体声。共享曲目表将低空智航条目追加在原五首后，以兼容旧版已保存的曲目索引。首页封套顺序独立于曲目表。

## 交互与会话

- 初次直达案例时等待手动播放。相同标签页内普通站内链接延续进度、音量、静音和暂停选择。换案例后使用新曲目；整页导航会带来短暂停顿。
- 首页换片在落针后播放。主动暂停会延续到首页。刷新恢复进度与设置，等待明确操作后出声。
- 新标签页等待手动播放。支持 BroadcastChannel 时，新标签页开始播放会暂停旧页。会话存储不可用时，手动播放仍可使用。
- 案例胶囊的彩胶只在实际播放时旋转。减弱动效关闭旋转，全屏媒体隐藏控件。播放失败在同一控件内提示。
- 独立打开的原型沿用原型页面自己的交互。

实现由 `src/scripts/home-music.js` 与 `src/scripts/music-session.js` 共用。控件尺寸和焦点规则见[设计规范](../../DESIGN.md#案例配乐--随行唱片)。

## 验证

运行 `npm run test:e2e -- tests/home-music.spec.mjs tests/case-music.spec.mjs`。专项覆盖六首曲目解码、首页与案例进度续接、暂停、静音、键盘、多窗口和减弱动效。首版随行唱片核验及浏览器环境限制见[2026-11-17 发布记录](../history/case-music-release-2026-11-17.md)。
