## 当前产品

产品采用本地 FastAPI 控制台与 Chrome 浏览器桥梁协作。用户在控制台录入批量主体，扩展自动准备执行网标签并逐项提交；出现安全验证时切到官网等待用户完成，随后自动读取列表与详情。页面验证状态仍有效时，下一项直接继续。

FastAPI 使用 SQLite 保存任务与结果，并按需生成 Excel。正常启动不加载 OCR、OpenCV、ONNX 或 openpyxl；Excel 库只在导出请求发生时加载。旧验证码求解代码只作为归档实验保留。
