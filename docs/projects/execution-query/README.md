# 执行网一键查询：项目记录

## 这组文档解决什么

这组文档保存旧项目的真实演进、技术试验、产品决定与作品集证据边界。旧目录继续只读，新版已在当前作品集工作区内独立实现。

项目的核心定位已经确认：它首先是给律师日常使用的生产工具，作品集价值来自真实问题、真实使用和可信证据，而不是另做一个只供展示的概念原型。

## 当前结论

- 值得进入作品集，核心价值是把真实重复劳动整理成可信的人机协作工具。
- 旧版业务经验可复用，技术架构建议重写。
- FastAPI 承担本地任务、历史记录、导出和扩展接口，不处理验证码。
- 验证码由用户在执行网页面完成。工具等待明确的验证状态，并自动接续批量任务。
- 新版证据必须来自实际查询会话；不再沿用旧版“注入数据后伪造 Safari 外壳”的截图方式。
- 公开案例已经创建。一次两项合成任务的真实浏览器小样本验收完成，公开页面保留样本和长期稳定性边界。

## 安全与材料边界

- 旧项目目录 /Users/second/Downloads/执行网一键查询/ 仅作为只读史料。
- 本目录只记录结构化结论，不复制查询历史、企业清单、案号、身份标识或未脱敏截图。
- 任何进入 public/ 的材料必须另做脱敏副本；原始证据不得公开。
- 验证码研究仅用于判断正常查询流程能否可靠自动化，不包含规避访问控制、对抗风控或高频抓取。
- 网站变更、网络异常、验证码失败和解析异常必须显式报错，不能被记录成“无执行记录”。
