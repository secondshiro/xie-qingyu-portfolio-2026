## 后续可复制的材料原则

只有在实施计划明确用途后，才从旧项目复制最小必要材料到新的隔离工作区。优先复制：

1. 去除敏感数据后的字段结构样本；
2. 历史比较规则的最小测试夹具；
3. Excel 列结构；
4. 能说明版本变化的少量代码片段或差异说明。

不复制完整历史数据库、客户预设名单、原始截图、虚拟环境或缓存。
