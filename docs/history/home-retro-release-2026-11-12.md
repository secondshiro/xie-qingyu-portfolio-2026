# 2026-11-12 首页复古唱机发布

用户确认双栏首页，并授权将本轮改动更新到线上。发布范围为首页唱机实现、对应测试、设计规范中的唱机章节及改前源码备份。

## 最终行为

- 灰白机身、浅木侧板、哑光零件和统一轻透视；保留原版五个封套、通栏作品介绍、A/B 面标签与方向控件。
- 点击唱机或透明盖可开合，Enter / 空格同样可用；换片先开盖，落针后恢复用户要求的开合状态。
- 离场 620ms、入场 820ms，快速改选只完成最后一次选择；各表面独立淡出，连续侧壁在移动中保持厚度。
- A/B 面绕唱片左右连线纵向翻转，支持连续切面与途中改选。
- 鼠标横向移动时整机同向轻转，最大 ±3°、320ms 缓动，离开后回正；换片或翻面时暂停，触屏与减弱动效关闭。
- 点击后使用方向快捷键不出现整机黑框；Tab / Shift+Tab 进入仍显示可见焦点。

## 验证

整站浏览器检查 138 项通过。最后反转跟随方向后，6 项跟随检查重新通过，并增加机身正面实际屏幕位移的断言。基础检查 7/7，类型检查无错误，六页静态构建成功。
