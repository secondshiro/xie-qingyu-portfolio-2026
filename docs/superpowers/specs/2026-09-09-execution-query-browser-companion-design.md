# 执行网浏览器伴生载体设计

## 1. 背景与结论

现有可行性实验得到两组同时成立的事实：

1. 用户正常 Chrome 会话中，执行网可以显示随机验证码，并已完成一次文字点选、列表查询和详情读取。
2. 独立 Playwright 会话即使使用专用持久 profile，也只能偶发加载基础资源；触发查询后验证码主体未创建，同一 profile 后续导航也不稳定。

因此，不再把“自动化工具自己启动一个浏览器”作为生产路线。新版采用 Chrome 浏览器扩展作为伴生载体，复用用户正常浏览器中的站点会话；FastAPI 继续负责本地图像识别、任务状态和后续数据能力。扩展不读取、复制或导出 Chrome 用户配置。

## 2. 产品目标

第一阶段只验证一个生产闭环：

> 用户在正常 Chrome 中打开执行网，扩展接管当前标签页，将随机验证码交给本地 FastAPI 识别并执行动作；验证成功后读取列表和详情，返回结构化本地结果。

通过标准：

- 扩展只能在 `https://zxgk.court.gov.cn/*` 激活。
- FastAPI 只监听 `127.0.0.1`，不接受局域网或公网连接。
- `SLIDER` 与 `WORD_IMAGE_CLICK` 每类至少各完成一次真实自动验证。
- 每次任务最多两次验证码动作；刷新后必须重新识别类型。
- 验证成功后必须在同一正常 Chrome 会话内取得列表和至少一个详情。
- 任何验证、页面或详情失败都显示为失败，不得转写成“无记录”。
- 不持久保存验证码图片、提示字、点击坐标、captchaId 或验证令牌。

未达到以上全部条件时，机器闸门继续保持 `conditional`。

## 3. 非目标

本阶段不实现：

- 批量名单、Excel 导入导出、SQLite 历史和差异比较。
- 云端部署、多用户、账号系统或远程任务。
- 自动清 Cookie、轮换 profile、伪造浏览器指纹或提高请求频率。
- `ROTATE`、`CONCAT` 等尚未在真实站点观察到的题型。
- 作品集详情页和首页入口。

这些能力只在浏览器伴生闭环通过后进入下一阶段。

## 4. 方案比较

### 4.1 Chrome MV3 扩展 + FastAPI（采用）

扩展运行在用户正常 Chrome 中，用最小权限观察当前执行网页面。题图送到本机 FastAPI 的短生命周期接口，FastAPI 返回高置信度动作。需要拖拽或点选时，扩展临时使用 Chrome 调试接口向当前标签页发送输入事件，动作完成后立即解除绑定。

优势是保留已被真实验证的浏览器会话环境，同时复用现有 Python 视觉处理器。代价是扩展安装时需要解释调试权限，并严格限制绑定范围和时长。

### 4.2 远程调试端口（不采用）

通过特殊启动参数开放 Chrome 调试端口，再由 Python 连接日常浏览器。它要求用户重启浏览器，并使调试能力暴露在一个长期端口上，权限面和使用成本都更大。

### 4.3 用户脚本（不采用）

用户脚本能够读取 DOM，但脚本合成的事件通常不具备真实输入语义，无法可靠覆盖滑块 SDK。它适合作为观察工具，不适合作为生产载体。

## 5. 架构

系统由四个边界清晰的组件组成：

### 5.1 扩展侧栏

职责：

- 显示本地服务是否在线。
- 接收单个查询词和可选身份/机构代码。
- 明确显示任务阶段、验证码题型、尝试次数和失败原因。
- 只有用户点击“开始查询”后才申请当前标签页权限。

第一阶段不显示完整历史，不在扩展存储中保存查询结果。

### 5.2 内容脚本

职责：

- 验证当前页面域名和查询页结构。
- 填写查询条件并触发站点原有查询按钮。
- 识别当前验证码 DOM 类型和元素尺寸。
- 返回当前验证码背景、模板或提示图的可见区域坐标；后台工作线程从当前可见标签页截图中只裁切这些区域，避免读取 Cookie 或页面存储。
- 验证成功后读取结果表格和详情结构。

内容脚本不得读取 Cookie、localStorage、sessionStorage 或 Chrome 用户目录。它只读取当前页面完成任务所需的可见 DOM。

### 5.3 后台服务工作线程

职责：

- 管理扩展状态和一次性任务 nonce。
- 只在任务运行期间附加到当前执行网标签页。
- 使用调试接口发送鼠标移动、按下、释放或点选事件。
- 动作完成、失败、标签页离开目标域名或任务取消时立即解除附加。

每次发送动作前再次校验标签页 URL；任何跨域导航都必须停止。

### 5.4 本地 FastAPI

职责：

- 验证扩展来源、任务 nonce、图片尺寸和请求体大小。
- 调用现有滑块或文字点选处理器。
- 返回题型、置信度和短生命周期动作，不返回或保存题图。
- 记录不含敏感内容的阶段证据：题型、耗时、结果、错误类别。

服务固定监听 `127.0.0.1`。扩展启动时生成 nonce，任务结束或超时后失效。API 不提供验证码图片回读接口。

## 6. 数据流

一次任务按以下顺序运行：

1. 用户在执行网查询页打开扩展侧栏并点击开始。
2. 扩展检查 FastAPI 健康状态、域名和页面契约。
3. 内容脚本填写查询条件，调用站点原有查询按钮。
4. 内容脚本等待验证码主体出现，读取题型和显示尺寸。
5. 内容脚本返回当前背景图、提示图或模板图的可见区域；后台工作线程用 `captureVisibleTab` 在内存中截图，只裁切这些区域，再把裁片连同一次性 nonce 发给 FastAPI。
6. FastAPI 在单任务临时目录中处理图片：
   - `SLIDER`：返回拖动距离、置信度和轨迹。
   - `WORD_IMAGE_CLICK`：返回按提示顺序排列的页面内坐标和置信度。
7. 若置信度低于阈值，任务停止，不执行页面动作。
8. 后台服务工作线程临时附加当前标签页，发送输入事件后立即解除附加。
9. 扩展等待验证成功、失败或题型刷新：
   - 成功：等待列表。
   - 失败或刷新：重新读取 DOM 类型，若尚未达到两次上限则重新路由。
   - 未知类型、资源异常或状态矛盾：停止。
10. 列表出现后，内容脚本读取当前页记录；逐条打开详情并标准化字段。
11. 扩展只把结构化结果交给本地 FastAPI 当前任务响应；验证码临时文件和动作数据立即销毁。

## 7. API 合同

### `GET /api/companion/health`

返回本地服务版本、伴生协议版本和是否可接受任务。不得返回本机路径。

### `POST /api/companion/session`

创建一次性会话，返回随机 nonce 和过期时间。只允许一个活动任务，默认五分钟失效。

### `POST /api/companion/solve`

请求字段：

- `nonce`
- `challenge_type`
- `background_image`
- `template_image`
- `display_size`

约束：

- 只接受 `SLIDER` 或 `WORD_IMAGE_CLICK`。
- 单张图片和总请求体都有固定上限。
- 图片解码后尺寸必须与声明比例一致。
- nonce 必须有效且属于当前活动任务。

响应只包含：

- `outcome`: `passed_candidate`、`retryable` 或 `unsupported`
- `challenge_type`
- `confidence`
- `action`: 拖动轨迹或有序点位
- `elapsed_ms`

响应不回传提示文字、OCR 文本或验证码图片。

### `POST /api/companion/result`

接收任务最终状态、记录数、脱敏错误类别和可选的本地结构化查询结果。只有后续历史功能批准后才写入 SQLite；第一阶段仅保存在进程内存中。

## 8. 权限与安全边界

扩展 manifest 使用：

- `host_permissions`: 仅 `https://zxgk.court.gov.cn/*` 和 `http://127.0.0.1/*`；Chrome 匹配模式在此写法下覆盖该主机的本地端口。
- `permissions`: `activeTab`、`scripting`、`sidePanel`、`debugger`。
- 不申请 `cookies`、`history`、`downloads` 或全站通配权限。

调试权限控制：

- 只有用户主动开始任务后附加。
- 附加前和每个动作前都校验标签页 URL。
- 一次只允许一个标签页、一个任务。
- 任务成功、失败、取消、超时或离开域名时立即解除。
- 不执行任意 JavaScript 字符串；所有动作必须匹配固定的、经 schema 验证的动作类型。

本地服务控制：

- 仅监听环回地址。
- CORS 只允许扩展自身 origin。
- nonce 只存在内存中，随机生成，五分钟过期，用后失效。
- 请求日志禁止记录图片正文、查询条件和站点令牌。

## 9. 错误处理

对用户只展示可行动、可区分的错误：

- 本地服务未启动。
- 当前标签页不是执行网查询页。
- 页面结构已变化。
- 验证码资源未加载。
- 题型暂不支持。
- 识别置信度不足，未执行动作。
- 验证失败且已达到两次上限。
- 验证通过但列表未出现。
- 列表已取得，但部分详情读取失败。
- 调试权限被拒绝或被其他工具占用。

失败状态不得生成空结果。部分详情失败时保留已取得列表，并逐条标记详情错误。

## 10. 最小界面

侧栏只包含四个区域：

1. 连接状态：本地服务、目标标签页。
2. 查询条件：姓名/名称、可选身份或机构代码。
3. 当前任务：阶段、题型、尝试次数、停止原因。
4. 本次结果：记录数量、详情完成数量和本地查看入口。

界面不复制执行网红色政务视觉，也不直接套用作品集页面。它采用当前作品集的中性色、橙色状态点和清晰排版，但保持生产工具所需的信息密度。视觉改版在闭环通过后单独进入设计规格。

## 11. 测试策略

### Python

- API schema、nonce 生命周期、CORS 和请求体上限。
- 图片只写入临时目录，并在成功、异常和取消后销毁。
- 两类处理器继续使用合成图像回归。
- 返回动作不包含图片、提示文字或站点令牌。

### 扩展

- manifest 权限快照测试。
- 域名和页面契约识别。
- 题型 DOM 提取与坐标缩放。
- 最多两次、刷新后重新路由。
- 调试附加和解除在成功、失败、取消、超时下都成对发生。
- 结果和详情标准化不把验证失败写成无记录。

### 真实低频验收

- 使用非敏感词“测试”。
- 每次运行前获得操作确认。
- 每轮最多两次验证码动作。
- 不保存题图、提示字、坐标或详情字段值。
- 分别观察到 `SLIDER` 和 `WORD_IMAGE_CLICK` 自动通过后，才把总闸门改为 passed。

## 12. 交付边界

第一阶段交付：

- 可加载的本地 Chrome 扩展目录。
- FastAPI 伴生接口。
- 两类处理器接线。
- 扩展与后端自动化测试。
- 安装、启动、权限说明和真实验收记录。

第一阶段不进入作品集。只有真实闭环通过后，才继续批量生产工具、界面改版、脱敏素材和案例页。
