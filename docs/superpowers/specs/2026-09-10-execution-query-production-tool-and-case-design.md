# 执行网查询生产工具与作品集案例设计规格

> 日期：2026-09-10  
> 状态：方向已由用户授权执行，功能发布仍受验证码闸门约束  
> 范围：本地生产工具、Chrome 伴侣、脱敏证据体系、作品集案例

## 1. 设计判断

这个项目适合进入作品集，前提是它先成为一件经真实任务验证的生产工具。案例的价值来自一条完整过程：律师重复查询的工作成本催生旧版，网站验证机制变化让旧链路失效，新版随后围绕可信状态、真实浏览器会话和本地处理重写。

生产工具与作品集页面共享颜色、字阶和克制的界面原则，信息密度保持不同。工具承担批量输入、任务队列、状态判断、历史比较和导出，使用紧凑工作台。案例页承担解释判断与展示证据，沿用现有“展开式作品册”。

不采用两种方向：一是把作品集的宽幅叙事布局直接搬进生产工具，这会降低批量扫描效率；二是制作一套与个人网站无关的通用蓝色后台，这会丢失项目辨识度，也会重复旧版的视觉问题。

## 2. 用户与核心任务

首版面向一名律师在本机使用，也允许同一设备上的小范围协作。用户需要完成五件事：

1. 粘贴或导入一批姓名及可选身份信息。
2. 看见每个主体正在经历的查询步骤。
3. 分清有记录、确认无记录和任务失败。
4. 与上一次成功查询比较新增、存续和撤销。
5. 导出一份能继续整理和交付的 Excel。

工具不承诺云端协作、多人权限、长期无人值守、绕过网站风控或永久兼容第三方网站。

## 3. 产品边界

### 3.1 Chrome 伴侣

伴侣只服务当前执行网页签和单次真实会话。它负责填入当前主体、识别眼前验证类型、取得页面内存图片、执行受限鼠标动作、读取列表与详情。它不读取 Cookie、历史记录、下载记录或浏览器用户目录，也不保存题图。

侧栏保留四区：

- 连接。显示本机服务与当前页面。
- 查询条件。用于单主体诊断和现场复验。
- 当前任务。显示验证、查询、详情读取与停止原因。
- 本次结果。显示当前会话中的记录和详情。

伴侣不是批量任务主界面。生产批量工作从本地工具开始，由本地服务逐项调度伴侣。

### 3.2 FastAPI 本地服务

FastAPI 是任务与数据边界。它提供批量任务、状态、历史、比较、导出与一次性伴侣会话。验证码处理器只负责给出候选动作与置信度，不能直接把失败写成无记录。

### 3.3 本地工作台

本地工作台是生产入口，运行在环回地址。页面包含：

1. 顶部状态栏。显示伴侣连接、目标网站状态和最近一次成功运行时间。
2. 批量输入区。支持逐行粘贴与 Excel 导入预览，提交前去重和标错。
3. 当前任务区。显示整体进度、当前主体、可取消操作和失败停止条件。
4. 结果表。按主体呈现最新状态、记录数量、变化状态、查询时间和详情入口。
5. 详情抽屉。展示本次记录、来源时间、历史变化和失败信息。
6. 历史与导出区。允许选择成功快照进行比较，导出当前任务或比较结果。

## 4. 信息架构

工作台使用三个顶层视图，避免把所有功能塞进一张长页。

### 当前任务

默认入口。左侧为批量输入或已提交的队列摘要，右侧为当前运行状态。任务开始后，输入区收为只读摘要，主空间让给队列和结果。

### 查询历史

按任务时间倒序排列。每个任务显示完成状态、主体数量、记录数量和失败数量。打开任务后复用结果表与详情抽屉。

### 历史比较

先选择同一主体的两个成功快照，再展示新增、存续与撤销。失败任务不能成为比较基线。

## 5. 状态模型与界面语言

状态必须对应用户下一步动作。

| 内部状态 | 界面文案 | 用户动作 |
| --- | --- | --- |
| queued | 等待查询 | 无需操作 |
| verifying | 正在完成安全验证 | 保持执行网页签开启 |
| searching | 正在查询 | 等待 |
| fetching_details | 正在读取详情 | 等待 |
| completed_with_records | 查询完成，有记录 | 查看详情或比较历史 |
| completed_no_records | 查询完成，无记录 | 可导出或结束 |
| verification_failed | 安全验证未完成 | 单项重试或稍后重跑 |
| site_changed | 网站页面已变化 | 停止批量任务并更新工具 |
| network_failed | 连接失败 | 检查网络后重试 |
| cancelled | 已取消 | 重新创建任务 |

界面不显示内部异常栈、英文题型名或验证码提示字。开发诊断只记录匿名阶段码、置信度、耗时和次数。

## 6. 数据模型

SQLite 保存生产数据，浏览器扩展不持久化任务。

- `subjects` 保存标准化主体与可选身份信息。
- `tasks` 保存任务起止时间、整体状态和适配器版本。
- `task_items` 保存每个主体的状态、尝试次数和失败分类。
- `snapshots` 保存一次成功查询的来源时间和结果摘要。
- `records` 保存标准化案件记录及其详情。
- `comparisons` 保存两个成功快照之间的新增、存续和撤销结果。

验证码图片、提示字、动作坐标、captchaId 与 pCode 不进入数据库。身份信息只存在于生产目录，公开证据目录只接收另行生成的脱敏副本。

## 7. 任务数据流

1. 用户粘贴或导入主体列表。
2. 前端本地校验，显示重复项和格式问题。
3. FastAPI 创建任务与队列，状态为等待查询。
4. 调度器逐项请求已连接的 Chrome 伴侣。
5. 伴侣在当前真实会话中完成验证、列表和详情读取。
6. FastAPI 校验完整性后写入成功快照，或保存明确失败状态。
7. 比较器只使用成功快照计算新增、存续和撤销。
8. 导出器从固定视图生成 Excel，不直接拼接页面文本。

任一主体失败不会污染其他主体。网站结构变化或连续验证失败达到上限时，整批暂停，避免持续产生不可信结果。

## 8. 生产工具视觉系统

工具沿用作品集的暖白、石色、墨色与橙色，但橙色只标记当前步骤和主要操作。风险、缓解、失败与等待使用独立语义色。

- 页面背景使用 `#f7f7f4`。
- 主文字使用 `#26251e`。
- 次级表面使用 `#eeede8`。
- 主操作与当前步骤使用 `#f54e00`。
- 新增记录使用克制红色。
- 撤销记录使用克制绿色。
- 失败使用红色图标与文字，不用整行高饱和填充。
- 等待和存续使用中性灰。

工作台采用企业工具密度。顶部高度 56px，主内容使用 12 列栅格，桌面最小有效宽度 1120px。表格表头吸附，数值右对齐，状态列保持固定宽度。详情从右侧 400至480px 抽屉打开，关闭后焦点返回原表格行。

表单始终使用可见标签。主要按钮采用动词开头，如“开始查询”“重试此项”“导出结果”。每个区域只保留一个主要按钮。空状态直接说明下一步，不使用装饰性插画占据主要空间。

## 9. 响应式与可访问性

生产工作台以桌面使用为主。宽度低于 900px 时，输入、进度与结果改为单列，结果表允许水平滚动，不隐藏关键列。手机宽度只提供任务状态与单项详情阅读，不承诺完成大批量整理。

每页只有一个 `h1`，第一焦点为跳到主内容链接。所有按钮与表单控件最小 44px。状态同时使用文字与图标表达。进度组件带有 `aria-valuenow`，异步状态使用克制的 `aria-live`。减弱动效下取消抽屉位移和加载动画。

## 10. 错误与恢复

- 验证低置信时不执行动作，显示具体可行动的中文停止原因。
- 两次验证失败后停止当前主体，不继续无限刷新。
- 页面合同变化时暂停整批任务，保留已成功结果。
- 详情部分失败时保留列表记录并标记详情缺失，不能伪装完整。
- 数据库写入失败时停止任务，不能只在界面显示成功。
- 重启服务后可读取上一次未完成任务，用户可以选择继续未完成项或创建新任务。
- 取消只停止未开始和当前主体，已成功快照保持可查。

## 11. Excel 导出

导出分为两种。

“当前结果”按主体、状态、立案日期、案号与详情字段输出，失败项单独保留状态与原因。“历史比较”按主体输出新增、存续和撤销，并在首行记录两个快照时间。

导出只来自成功写入的数据库视图。身份证明字段默认脱敏展示，用户明确选择后才输出完整值。公开作品集永远不使用生产导出原件。

## 12. 作品集案例结构

发布路由拟定为 `/work/execution-query/`，在验证码、历史比较、导出和真实证据全部通过闸门前不创建公开入口。

案例使用八个章节。

1. 起点。一次查询很简单，批量复核持续消耗时间。
2. 演进。旧版从单次脚本增加批量、进度、历史与 Excel。
3. 语义修正。新增代表风险，撤销代表缓解，状态颜色随业务含义调整。
4. 失效。网站从字符图片切换到随机交互验证，旧请求链路停止工作。
5. 闸门。先证明真实浏览器闭环，再决定是否继续生产重构。
6. 重构。FastAPI 管理任务与数据，Chrome 伴侣保留真实网站会话。
7. 生产工作台。展示失败分流、任务队列、历史比较和导出。
8. 阶段边界。标明验证日期、已验证范围与第三方网站变化风险。

首屏主张控制在可证明范围内。建议标题为“把重复查询改成可信的本地工作流”，导语说明项目经历了旧版迭代、网站验证变化和一次生产重写。页面不使用“完全自动”“零人工”“永久可用”、未经验证的成功率或节省时间。

## 13. 作品集视觉材料

公开页面只使用经过脱敏的真实材料。

- 旧版四阶段演进图，由源码差异和已确认功能生成。
- 随机验证码路由图，只展示类型和状态，不展示题图。
- “失败不能写成无结果”的状态分流图。
- 新版批量工作台真实截图。
- 单个主体的验证、查询、详情与快照链路。
- 同一主体历史比较的新增、存续和撤销。
- 脱敏 Excel 导出片段。
- 旧界面与新版信息层级对照。

作品集页面继续使用 `CaseHero`、`CaseSection`、`CaseToc` 与 `MediaStage`。主标题、章节标题、目录、容器和窄屏行为完全继承现有视觉合同，不另建一套案例模板。

## 14. 发布闸门

满足以下条件以后才创建公开案例页和首页入口。

1. `SLIDER` 与 `WORD_IMAGE_CLICK` 都在真实 Chrome 中自动通过。
2. 同一会话能可靠区分有记录、确认无记录和失败。
3. 列表与详情闭环通过有限连续任务验收。
4. SQLite 快照和新增、存续、撤销比较通过固定夹具。
5. 两种 Excel 导出与固定预期逐列一致。
6. 至少形成一组真实会话的脱敏截图或录屏。
7. 公开页面不包含身份信息、案号原文、验证码图片和未经证明的指标。

若验证码真实验收继续失败，生产工具和作品集案例都停在阶段记录，不用人工验证冒充自动生产能力。

## 15. 验证策略

### 工具测试

- Python 单元测试覆盖状态机、SQLite、比较、导出和处理器。
- FastAPI 集成测试覆盖任务创建、查询、取消、恢复与错误合同。
- 扩展测试覆盖权限、当前页合同、两次路由、可信输入和无持久存储。
- 真实低频验收分别覆盖两类验证码、记录、空结果、详情和下一任务清理。

### 工具视觉与行为

- 1440px、1120px、900px 和 390px 检查布局与溢出。
- 键盘完成批量输入、开始、取消、查看详情、关闭抽屉和导出。
- 减弱动效下保持完整状态反馈。
- 表格长字段、空数据、部分详情失败和大量队列均有稳定布局。

### 作品集页面

- 运行现有内容边界测试，新增执行网案例的敏感内容扫描。
- 运行 `npm test`、`npm run test:e2e` 与 `npm run build`。
- 检查四档宽度、键盘焦点、目录状态、媒体比例和窄屏降级。
- 人工核对所有主张都能追溯到源码、真实运行或脱敏证据。

## 16. 当前执行顺序

1. 重启本机 FastAPI，真实复验带提示字约束的 Vision 与透明轮廓滑块。
2. 两类通过后实现 SQLite 领域层与任务 API。
3. 实现批量工作台、历史比较和 Excel 导出。
4. 完成真实连续任务验收并制作脱敏证据。
5. 创建作品集案例页，通过整站验证后加入首页入口。
