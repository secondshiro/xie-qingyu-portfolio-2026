# 执行网查询助手本地控制台设计

> 日期：2026-09-12  
> 状态：已按用户授权冻结，进入实施  
> 延续：`2026-09-10-execution-query-assistant-human-verification-design.md`

## 1. 产品判断

Chrome 扩展继续承担执行网页面适配，但不再承担产品主界面。本地控制台成为用户开始任务、观察进度、查看历史和导出结果的唯一主入口。用户无需预先打开执行网；查询开始后，扩展自动寻找已有查询页，找不到时在后台打开。

出现安全验证时，工具把执行网页面切到前台并等待用户完成。验证成功后，扩展继续当前批次，控制台持续显示任务状态。验证码始终由用户处理，不接入自动识别、自动拖动或第三方打码。

## 2. 选择的方案

采用 FastAPI 本地控制台与 Chrome 浏览器桥梁。

- FastAPI 提供同源控制台、任务 API、SQLite 历史和 Excel 下载。
- Chrome 扩展负责执行网页面的打开、复用、填表、验证等待、列表和详情读取。
- 控制台页面通过限定在 `127.0.0.1:51997` 的内容脚本向扩展发送命令。
- 扩展只回传任务编号、阶段和计数，不通过浏览器消息广播身份号码或案件详情。

没有选择继续强化侧栏，因为该入口仍要求用户先理解执行网页面与扩展之间的关系。没有选择 Electron 或 Tauri，因为验证码仍要依赖真实浏览器会话，桌面壳会增加打包、签名和双运行时维护成本。

## 3. 主流程

1. 用户打开本地“执行网查询助手”。
2. 用户逐行录入主体，可附身份或机构代码。
3. 控制台检查本地服务和浏览器桥梁，随后开始批量任务。
4. 扩展复用已有执行网查询页，或在后台新建查询页并等待加载。
5. 页面要求验证时，扩展激活该标签；控制台同步显示“请在执行网页面完成验证”。
6. 用户验证后，扩展自动继续查询并整理详情。
7. 批次完成、暂停或取消后，用户在控制台查看逐项状态并下载 Excel。

侧栏继续保留为诊断和兼容入口，但不再是推荐工作流。

## 4. 控制台结构

控制台采用紧凑工作台，不复制作品集页面布局。

- 顶栏显示产品名、浏览器桥梁状态和本地保存说明。
- 主区左侧是批量输入和唯一主操作“开始批量查询”。
- 主区右侧是当前任务，包含总数、已完成、有记录、无记录和失败计数。
- 下方是逐项状态列表和最近任务。
- 验证提示使用靠近当前任务的内联警告，并提供“前往验证”操作。
- 没有任务时直接解释第一步，不显示空白表格或装饰性仪表盘。

视觉使用暖白、墨色、石色和单一橙色信号，与作品集保持同一设计语言；工作台密度更高。页面只有一个 `h1`，控件至少 44px，包含跳到主内容链接、可见焦点和减弱动效支持。

## 5. 浏览器桥梁合同

本地控制台与内容脚本使用显式消息信封。

- 来源必须精确等于 `http://127.0.0.1:51997`。
- `event.source` 必须是当前 `window`。
- 请求只允许检查状态、开始批次、继续任务、取消任务和前往验证。
- 每个请求包含一次性请求编号，响应必须带回相同编号。
- 内容脚本不得接收或转发任意网页来源的命令。
- 广播进度只包含任务编号、当前位置、总数、已完成数和当前主体名称；身份号码与查询记录不进入广播。

## 6. 标签页行为

- 优先复用当前 Chrome 窗口中已打开的执行网查询页。
- 没有可用页面时，在发起控制台所在窗口后台打开官方查询地址。
- 运行前检查页面地址、加载状态和表单合同。
- 安全验证出现时激活执行网页签。
- 批次完成、暂停或取消后，若控制台标签仍存在则切回控制台。
- 详情页继续作为临时标签打开，读取后关闭。

## 7. 暂停与继续

验证超时、网络失败和可恢复的页面异常会停止当前批次。当前失败项保持失败语义，剩余项目保持排队，任务状态改为 `paused`，避免永久显示 `running`。

用户点击“继续任务”时，可恢复失败项会重新进入队列，并从第一个待处理项目开始。明确的页面结构变化不能直接继续，界面应提示先更新适配器。取消仍会保留已完成结果，并把未完成项标为取消。

## 8. 启动边界

第一阶段由现有 `execution-query serve` 启动本地服务，并自动打开控制台。后续可以增加 macOS 启动器或登录项，但不在本阶段引入桌面壳。控制台必须清楚区分“本地服务已运行”和“浏览器桥梁已连接”。

## 9. 数据与安全

- 生产数据只写入本地 SQLite。
- 验证码图片、提示、坐标和页面票据不持久化。
- 控制台不把任务内容写入 `localStorage` 或其他浏览器持久存储。
- FastAPI 的任务写入允许固定扩展来源与本地控制台同源请求，拒绝其他网页来源。
- Excel 只在用户点击时生成并返回，不在服务器保存副本。

## 10. 验收标准

- 打开本地控制台即可开始工作，不要求用户先打开执行网。
- 扩展能自动复用或创建执行网查询页。
- 验证出现时自动切到官网，用户完成后批次继续。
- 控制台可查看当前任务、逐项状态、最近历史、取消和导出。
- 单项失败后整批进入 `paused`，剩余项目不再造成永久 `running`。
- 可恢复任务能够继续，不覆盖此前成功结果。
- 未安装扩展或桥梁离线时，控制台给出可行动说明。
- Python、扩展和控制台相关自动化测试通过，并完成真实 Chrome 人工验证验收。
