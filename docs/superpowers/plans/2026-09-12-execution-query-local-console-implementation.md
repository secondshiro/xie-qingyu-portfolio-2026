# 执行网查询助手本地控制台实施计划

> 对应规格：`docs/superpowers/specs/2026-09-12-execution-query-local-console-design.md`

**目标：** 把现有 Chrome 侧栏工作流升级为以 FastAPI 本地控制台为主入口的生产工具，扩展在后台自动打开或复用执行网页面，只在人工验证时把官网带到前台。

**架构：** FastAPI 提供同源 HTML、CSS、JavaScript 和任务读取接口。受限内容脚本连接本地页面与 MV3 service worker。service worker 继续调用现有页面适配器和任务 API，并负责执行网页签生命周期。

## Task 1：修正暂停语义

- [x] 先写仓库和 API 失败测试，证明可恢复失败且仍有排队项时任务为 `paused`。
- [x] 增加继续任务合同，重新排队验证超时和网络失败项，保留已完成结果。
- [x] 页面结构变化保持不可直接继续。
- [x] 服务重启把中断的 `running` 任务恢复为 `paused`。

## Task 2：浏览器标签调度

- [x] 开始任务时不再要求当前活动标签就是执行网。
- [x] 验证出现时激活执行网页签，结束后回到控制台标签。
- [x] 保留侧栏入口兼容行为。

## Task 3：安全的本地桥梁

## Task 4：FastAPI 控制台

## Task 7：恢复历史变化比较

- [x] 从旧版提取“按主体比较最近成功快照”的业务规则，不复制历史敏感数据。
- [x] 首次记录、新增、存续和本次未见采用派生状态，不修改原始查询快照。
- [x] 失败或未完成项不参与比较，避免把失败解释成记录消失。

## 计划自检

- 计划直接消除“必须先打开执行网再使用扩展”的入口摩擦。
- 现有 FastAPI、SQLite、Excel 和页面适配器均继续复用。
- 验证码边界没有扩大，仍由用户在官网处理。
- 本阶段不引入桌面壳和无人值守定时查询。
- 未包含 Git 提交步骤，符合当前工作区约束。
