# GIS 页面转场实施计划

> 在当前会话按步骤执行。用户已授权制作试版；本轮不提交、不推送，不分派子代理。

**目标** 让首页与 GIS 案例通过 660 毫秒石色短转场衔接。

**结构** 点击时先遮盖旧页，遮盖完成后进行原生导航；目标页头部脚本在首次绘制前接续遮盖。条件入口控制试版范围，页面保持独立加载。首页补充返回时的选择恢复。

**技术** Astro 静态页面、固定伪元素的 CSS 动画、浏览器会话存储与 Playwright。

- [x] 创建 `src/components/PageTransitionHead.astro` 与 `src/styles/page-transition.css`。
